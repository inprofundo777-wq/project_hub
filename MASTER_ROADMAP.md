# MASTER ROADMAP — In Profundo

**Статус:** активный рабочий документ  
**Назначение:** единая операционная карта проекта  
**Период пересмотра:** по необходимости и не реже одного раза в неделю

---

## Как пользоваться документом

Этот файл хранит:

- цикличные задачи;
- текущие открытые шаги;
- стратегические направления;
- краткие описания будущих идей;
- необходимые ссылки;
- историю завершённой работы.

Главный принцип:

> Сначала закрывается текущий цикл публикаций. После этого открывается окно возможностей для развития других направлений.

Во время работы выполненные пункты отмечаются галочкой:

- [ ] открыто;
- [x] выполнено.

При очередном обзоре:

1. выполненные действия переносятся в раздел «История работы»;
2. незавершённые действия сохраняются;
3. регулярные циклы обновляются на следующий период;
4. добавляются новые необходимые шаги;
5. определяется один главный приоритет и, при наличии ресурса, одно окно возможностей.

---

# 1. Текущий операционный статус

## Главный приоритет

**Закрыть текущий недельный цикл публикаций.**

Состояние на текущий понедельник:

- [x] Основная статья подготовлена.
- [ ] Подготовить визуал для статьи.
- [ ] Провести финальную подготовку статьи к публикации.
- [ ] Опубликовать статью в блоге.
- [ ] Подготовить Telegram-публикации по теме статьи.
- [ ] Поставить Telegram-публикации в отложенную очередь.
- [ ] Подготовить Facebook-публикации по теме статьи.
- [ ] Подготовить визуалы для Facebook.
- [ ] Поставить готовые Facebook-публикации в отложенную очередь.
- [ ] Определить тему следующей статьи.
- [ ] Наметить темы статей на ближайшие недели.

## Сигнал состояния контента

**Красный:** текущая неделя не покрыта.  
**Жёлтый:** текущая неделя покрыта, следующая ещё нет.  
**Зелёный:** публикации подготовлены минимум на две недели вперёд.

**Текущий сигнал:** красный.

# 2. Еженедельный цикл публикаций

Цель: одна статья по понедельникам.

### Текущий цикл

- [x] Идея и тема.

### Следующий цикл

## 2.2. Telegram

Цель: 1–2 публикации в день.

Основные форматы:

- «Вечное Слово»;
- рефлексии по статье недели;
- короткие размышления;
- различение;
- вопросы и опросы;
- воскресный вход;
- вечерний стих.

### Текущая неделя

- [ ] Подготовить план публикаций на неделю.
- [ ] Подготовить публикации «Вечное Слово».
- [ ] Подготовить рефлексии по статье недели.
- [ ] Проверить библейские ссылки и цитаты.
- [ ] Передать тексты через Telegram Editor.
- [ ] Поставить готовые материалы в отложенную публикацию.
- [ ] Проверить, что неделя покрыта полностью.

### Целевое состояние на август

- [ ] Добиться устойчивого недельного покрытия.
- [ ] Перейти к подготовке контента на две недели вперёд.
- [ ] Поддерживать зелёный сигнал без избыточного давления.

## 2.3. Facebook

Цель: одна публикация в день.

Основные форматы:

- рефлексии по статье;
- короткие посты;
- смысловые карты;
- карусели;
- цитаты;
- визуальные публикации;
- мягкая ссылка на блог.

### Текущая неделя

- [ ] Подготовить серию публикаций по статье недели.
- [ ] Передать тексты через Facebook Editor.
- [ ] Подготовить визуалы через Visual Editor 2.
- [ ] Проверить библейскую основу.
- [ ] Поставить готовые материалы в отложенную публикацию.
- [ ] Проверить, что неделя покрыта полностью.

### Целевое состояние на август

- [ ] Поддерживать готовую очередь минимум на одну неделю.
- [ ] Перейти к покрытию на две недели вперёд.
- [ ] Сформировать резерв универсальных публикаций на случай перегрузки.

# 10. Идеи развития

Идеи хранятся здесь, чтобы к ним можно было вернуться без повторного восстановления контекста.

## «Взгляд»

**Статус:** идея / исследование концепции.

**Суть:** направление, которое развивается через наблюдение, интуицию, малые практические шаги и последующее переосмысление.

- [ ] Восстановить предыдущее обсуждение концепции.
- [ ] Кратко описать её смысл.
- [ ] Определить первый реальный эксперимент.
- [ ] Провести эксперимент без обязательства превращать идею в постоянное направление.
- [ ] Через установленный период пересмотреть результат.
- [ ] Принять решение: развивать, изменить или закрыть.

## Шаблон новой идеи

```markdown
### Название идеи

**Статус:** интуиция / исследование / эксперимент / пауза.

**Суть:** краткое описание.

**Что уже понятно:** ...

**Следующий возможный шаг:** ...

**Ссылка:** ...
```
